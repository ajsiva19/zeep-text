# Turtle Shell Mortgage Partners

A professional mortgage services website built with **React**, **Tailwind CSS**, **React Router**, and **Framer Motion**.

## Design

- **Color palette:** Navy blue (#0A1628) and metallic gold (#D4AF37)
- **Typography:** Montserrat
- **Responsive:** Mobile-first layout with hamburger navigation

## Pages

| Route | Page |
|-------|------|
| `/` | Home |
| `/about` | About Us |
| `/services` | Mortgage Services |
| `/first-time-buyers` | First-Time Home Buyers |
| `/how-it-works` | How It Works |
| `/knowledge-hub` | Knowledge Hub / Blog |
| `/faq` | FAQ |
| `/contact` | Contact (with enquiry form) |

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build for Production

```bash
npm run build
npm run preview
```

## Customization

- **Logo:** Replace `public/logo.png`
- **Contact info:** Update phone, email, and address in `src/components/layout/Footer.jsx` and `src/pages/Contact.jsx`
- **Hero images:** Update URLs in `src/data/content.js`
